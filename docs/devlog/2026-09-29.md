## M2.1 — deterministic math kernels and backward passes

Task: `td-452dcf`

Changed files: A minimal tensor representation backed by `Float32Array`, a serializable seeded RNG,
and explicit forward/cache/backward implementations for add, whole-tensor reductions, 2D and
batched matrix multiplication, last-axis softmax, LayerNorm, tanh-approximation GELU, embedding
lookup/scatter-add, and mean cross-entropy with an optional ignored target.

Contract implemented: Tensor construction and every kernel boundary reject invalid shapes and
non-finite values. The RNG preserves its pending Box-Muller value in snapshots. Softmax uses
maximum subtraction, and cross-entropy calculates log-sum-exp directly so a target probability
that underflows in Float32 still produces a finite loss. Caches are plain inspectable values and all
backward functions are explicitly callable for the transformer gradient checker.

## M2.2 — parameter registry and versioned checkpoint I/O

Task: `td-c4d6d3`

Changed files: The exact default model configuration, authoritative named parameter registry,
checkpoint configuration schema, little-endian Float32 weight encoder/decoder, and Node checkpoint
directory store with validated temporary writes and atomic installation.

Contract implemented: The registry defines all 36 default parameters once and reports exactly
169,728 elements. It supplies fixed ordering, shapes, parameter kind, AdamW decay eligibility,
values, and gradients for initialization, serialization, the future optimizer, and the future
parameter explorer. Seeded initialization uses standard deviation 0.02 for embeddings/matrices,
zeros for linear biases and LayerNorm offsets, and ones for LayerNorm scales. Untied and bias-free
configurations are explicit variants rather than hidden special cases.

Checkpoint format version 1 stores complete model/optimizer/provenance configuration,
`weights.index.json` as the ordering authority, little-endian `weights.bin`, and the training log.
The writer refuses to overwrite existing paths, writes a private temporary sibling directory,
reloads and validates every artifact, and only then atomically renames it into place.

- `npm run check` — passed with 0 errors and 0 warnings.
- `npm run test:run` — passed 85 tests across 15 files. New coverage asserts exact default names,

  atomic installation; existing-path preservation; and rejection of duplicate, missing,
  unexpected, overlapping, gapped, truncated, trailing, unsupported-version, invalid-metadata, and

- `npm run build` — passed.

Known limitations: Optimizer moment state and resumable data/RNG state are intentionally deferred to

## M2.3 — one pre-LayerNorm transformer block and checked gradients

Task: `td-91372b`

Changed files: Explicit linear forward/backward kernels, mask-aware stable softmax, scaled
dot-product attention, head split/merge, multi-head Q/K/V/output projections, and a complete
pre-LayerNorm attention-plus-MLP residual block with explicit caches and backward functions.

Contract implemented: Attention uses the configured `1 / sqrt(dHead)` scale. Causal and padding
masks are combined independently for every batch/head; disallowed scores are treated
mathematically as negative infinity without storing non-finite tensor values. A fully padded query
has an all-zero probability row and zero score gradient. The block implements
`x + attention(ln1(x))`, then `x + mlp(ln2(x))`, with separate parameter gradients for every named
registry entry it consumes.

Gradient verification: The tiny checked configuration uses width 4, two heads of width 2, MLP
width 5, three tokens, and a padded final token. An independent test-only Float64 implementation
computes the complete block objective. Central differences use epsilon `1e-4`; every element of all
16 block parameter groups and every input element must have relative error below `1e-3`, with an
absolute-error bound of `2e-5` when both values are near zero. All checks passed.
